# HRE4M1 Christlike Character Lab

[Open the classroom app](https://fslb10.github.io/hre4m1-character-lab/)

**Echoes of the Incarnation** is a Grade 12 Catholic religion activity for HRE4M1 Unit 1.4. Students work in pairs or groups of three, investigate a figure, answer the original three assignment questions using specific evidence, explain why Jesus alone is God incarnate, and present their findings.

The app includes 13 character profiles, source and story-version reading notes, Gospel reference panels, a custom figure option, saved group responses, a presentation view, and a downloadable or printable group report. The Unit 1.4 Word handout is available in the app's Activity guide. The two activities have separate handouts:

- [Unit 1.4 Christlike Character Lab](handouts/HRE4M1_Unit_1_4_Character_Lab.docx)
- [Unit 1.5 System Failure](handouts/HRE4M1_Unit_1_5_System_Failure.docx)

## Student use

No installation or student account is required. Answers save only in the current browser on the current device. Students should download their group report before leaving a shared computer. Answers are not uploaded or submitted to a teacher, and the app does not synchronize group members' devices. Saved answers from a different hosting address do not automatically transfer.

## Publishing and updates

This repository contains only the published app and its handouts. GitHub Pages serves the `main` branch from the repository root. The `.nojekyll` file allows the static files to be published directly. Changes pushed to `main` publish automatically.

All app assets use relative paths. No external scripts or fonts are required. External references open when clicked.

## Content

Profiles identify their historical source or narrative version. Suggested Christlike connections are prompts for students' reasoning. Christlike qualities do not make a figure God incarnate. Aslan is identified as an intentional literary representation of Christ, and mythological divine ancestry is distinguished from Catholic Incarnation theology.

Theological references: John 1:1-14 and Catechism of the Catholic Church 461-464, 480-483. See [the source review](SOURCE_AUDIT.md) for the character link audit.
